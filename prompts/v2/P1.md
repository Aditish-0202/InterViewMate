# P1 — Interview answer evaluation (v2 weighted rubric)

Status: historical experiment, **not** the deployed prompt.

## Prompt

Coach the candidate using the role, question and answer supplied. Score relevance 0–3, clarity 0–2, structure 0–2 and role-specific skills 0–3. Add the four integers. Return the breakdown, total, one strength, one specific improvement, a rewritten answer and one relevant follow-up. Use only facts stated by the candidate.

## Template variables
- `{role}`: selected interview role
- `{question}`: question being answered
- `{answer}`: candidate's typed response

## Recorded result (22 Nov 2026)
The accessibility sample received 2 + 1 + 1 + 1 = 5/10. The rewrite still claimed a Lighthouse audit the candidate did not report. See the Milestone 2 PDF, Section 3.
